01 · Choose an algorithm

資料是否排序，會改變選擇

互動比較

先驗證前提，再比較搜尋步數

線性搜尋可處理未排序資料；二分搜尋須使用排序資料。若只搜尋一次，也要把預先排序的成本計入。

比較資料移動，不只比較答案

排序每次主要動作常見 trace 重點
Bubble相鄰比較，逆序便交換每輪末端已有最大／最小項
Insertion把目前項插入已排序部分移位後才放回 current item
Selection在未排序部分找極值再交換每輪通常只作一次交換
課程只要求認識：merge sort 和 quick sort 應知道是更進階的排序方法；答題仍要按資料規模、是否已排序及實作要求解釋選擇。

02 · Data structures

物理位置、指標與操作規則

Stack 與 circular queue

Stack 後進先出，Queue 先進先出。加入前檢查 overflow，移除前檢查 underflow；循環隊列用 count 分清空滿，利用取模重用空位。

用 data、next 及 head 表示鏈表

邏輯相鄰不等於物理相鄰。插入先保存後繼鏈結，刪除先把前驅接到後繼，再把空位交回 free list。

03 · Files and program quality

把狀態、檔案與模組分開檢查

文字檔案

開啟、逐筆處理、關閉；更新變長記錄時先寫暫存檔，再確認並取代原檔。目標不存在時不能修改另一筆記錄。

子程式的局部框架與回傳

每次呼叫建立參數及局部變量。return 把結果交給呼叫者，離開後本次局部框架移除。

修改物件與重新綁定參數不同

Python 中，列表參數可能與呼叫者共同指向同一物件；append 修改物件，items = [...] 則只改局部綁定。

內外迴圈的執行次數

固定列、欄各跑 n、m 次共 n×m 次；內層範圍依賴外層時須逐列相加。每列開始須重設列總和，不能誤把全表總和清零。

數值精度與範圍

捨入與截斷會產生不同近似值；另須考慮固定字長的 overflow、浮點 underflow 及表示誤差。

可觀察及可維護的程式

Breakpoint 暫停到指定位置，trace table 記錄變量，flag／日誌保留關鍵狀態，stub 暫代未完成模組。使用有意義命名、縮排、適量註解與模組，避免重複邏輯；結構化程式以 sequence、selection、iteration 表達流程。

04 · Original DSE-style practice

搜尋與堆疊：9 分

9 分
原創練習按公開課程範圍設計，並非歷屆試題。
陣列 A 儲存 [4, 9, 13, 18, 25, 31, 42]。程式要尋找 25，並用 stack 保存使用者最近開啟的三個頁面。

  1. (a) 說明 binary search 適用的原因，並列出直至找到 25 的中間項。

    [4 分]

    資料已排序（1）；可每次排除一半範圍（1）；中間項依次為 18（1）、31、25（次序全對 1）。

  2. (b) 寫出 push 前和 pop 前各要檢查的錯誤。

    [2 分]

    push 前檢查 overflow／stack full（1）；pop 前檢查 underflow／stack empty（1）。

  3. (c) 指出 breakpoint 和 trace table 在除錯時各一項用途。

    [3 分]

    Breakpoint 在指定位置暫停執行（1）以檢查狀態（1）；trace table 逐步記錄變數／條件變化（1）。
