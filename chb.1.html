01 · Functional units

五類硬件如何合作

課程核心

一個計算工作通常不是由 CPU 單獨完成。原始數據經輸入，指令與數據在記憶體、CPU 和裝置之間傳送，最後以合適形式輸出或長期儲存。

IN

輸入裝置

把文字、圖像、聲音或物理量轉成電腦可處理的數據。

MEM

主記憶體

暫存正在使用的指令、數據和中間結果。

CPU

處理單元

擷取、解碼及執行指令，進行運算並控制其他部件。

SSD

儲存裝置

在沒有電源時仍長期保存程式和數據。

OUT

輸出裝置

把結果轉成畫面、聲音、打印文件或其他可用形式。

02 · Processing units

CPU 結構與 GPU 的不同強項

Control unit

控制單元（CU）

解碼指令，發出控制訊號並協調 CPU、記憶體及輸入輸出裝置的工作。

解碼 · 控制 · 協調

Arithmetic logic unit

算術邏輯單元（ALU）

執行加減等算術運算，以及比較、AND、OR、NOT 等邏輯運算。

算術 · 比較 · 邏輯

Registers

暫存器

位於 CPU 內的高速小容量儲存位置，暫存地址、指令、數據或中間結果。

最接近 CPU · 容量小 · 速度高

Central processing unit

CPU

以少量較強的核心處理通用、順序和控制密集的指令。頻率常以 Hz、MHz 或 GHz 表示每秒周期數。

Graphics processing unit

GPU

以大量較小的處理核心同時處理可分拆的工作，常用於圖像、視像及 AI 矩陣運算。

Performance reminder

不要只看 GHz

頻率較高代表周期較多，但整體效能亦受核心數、架構、快取、記憶體速度和工作類型影響。

06 · Original DSE-style practice

智能溫室電腦系統：7 分

7 分
原創練習按課程範圍和公開評核常見指令詞編寫，並非歷屆試題或官方擬題。
智能溫室每分鐘量度溫度。電腦會處理讀數、在屏幕顯示趨勢，並把全年的記錄保存作分析。

  1. (a) 建議一種合適的輸入裝置，並解釋它如何減少人手工作。

    [2 分]

    溫度感應器（1）；可自動、定時把物理溫度轉成輸入數據，毋須人手量度或抄錄（1）。

  2. (b) 指出 CPU 中負責解碼指令和進行比較運算的部件。

    [2 分]

    解碼指令：控制單元（CU）（1）；比較運算：算術邏輯單元（ALU）（1）。

  3. (c) 解釋 RAM 與 SSD 在這個系統中的不同用途，並指出哪一種屬揮發性。

    [3 分]
    • RAM 暫存正在執行的程式、讀數或中間結果（1）。
    • SSD 在關機後仍長期保存全年記錄（1）。
    • RAM 屬揮發性；SSD 屬非揮發性（1）。
