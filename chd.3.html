01 · Program building blocks

狀態、運算和資料流

變數

以名稱保存運行期間會改變的值，例如 total、count、found 和 index。

常數

代表運行期間不應改變的命名值，例如 PASS_MARK 或 MAX_SIZE，減少散落的「神奇數字」。

賦值

先計算右方表達式，再把結果存入左方變數。count ← count + 1 是更新，不是數學等式。

輸入／輸出

input 取得外部資料；output 呈現結果。提示文字、格式和錯誤訊息也是介面設計。

02 · Operators and expressions

同一表達式可產生數值或 Boolean

算術

＋、−、×、÷ 及 modulus。括號可清楚指定運算次序；mod 常用於餘數、倍數和循環模式。

關係

等於、不等於、大於、小於及其包含端點形式，結果是 true 或 false。

Boolean

AND、OR、NOT 組合條件。要留意自然語言中的「同時」和「至少一項」。

資料類型

運算必須配合類型；以字串形式保存的 "10" 不一定與整數 10 有相同行為。

即時判斷

判斷 age 是否介乎 12 至 18（包括端點），兩個限制應以甚麼連接？

選擇答案後會顯示解釋。

03 · Selection and iteration

控制流程決定哪些語句會執行多少次

巢狀迴圈不在要求內

選擇：成績分類

if score >= 80
    grade ← "A"
elseif score >= 60
    grade ← "B"
else
    grade ← "C"

迭代：輸入至哨兵值

input n
while n ≠ 0
    total ← total + n
    input n
output total
常見錯誤：multi-way selection 的條件次序會影響結果；while 迴圈內若沒有更新控制變數，可能永不停止。

05 · Required problem patterns

必修常見列表與字串任務

最小／最大／平均

初始化 extreme 值及 total，再逐一比較或累加；平均值要考慮項目數和實數類型。

搜尋與報告

逐一比較目標；可用 found Boolean 記錄結果，並按是否找到輸出適當訊息。

計數符合條件

count 從 0 開始，只在指定條件成立時增加 1。

次序檢查

比較相鄰元素；任何一對違反升／降序規則便可標記未排序。

字串長度

取得或逐字符計算長度；索引起點按指定語言／題目表示法。

擷取字符

按起點和長度／終點取出所需部分，留意終點是否包括在內。

增加／刪除項目

固定陣列可能需要移動後續元素；動態列表仍須更新索引和長度。

數學公式

把公式分成清楚子表達式，使用括號控制次序，並檢查單位和除數。

06 · Original DSE-style practice

列表計數與迴圈修正：8 分

8 分
原創練習按 D(c) 列表、選擇和迭代要求編寫。

  1. (a) 寫出偽代碼，計算列表 mark 中不少於 60 的項目數。

    [4 分]
    • count 初始化為 0（1）。
    • 以迴圈處理每個元素（1）。
    • mark[i] ≥ 60 時 count 增加 1（1）。
    • 迴圈後輸出 count（1）。

  2. (b) while n≠0 內只有 total←total+n。說明為何可能永不停止及如何修正。

    [2 分]

    n 在迴圈內沒有更新，所以條件可永遠保持 true（1）；在迴圈內再次輸入／更新 n（1）。

  3. (c) total 及 count 通常應使用甚麼初值？

    [2 分]

    total = 0（1）；count = 0（1）。
