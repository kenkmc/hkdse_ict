# 原創情境及圖像微課圖片

本資料夾的圖片由 OpenAI 內建 ImageGen 於 2026-08-29 生成，供 26 個課程頁的分層課業及「圖像微課」使用。圖片不含品牌標誌、商標、可識別個人資料或第三方素材；課題標題、說明及替代文字由網頁以繁體中文提供。

## 最終 prompt set

- `smart-school-data.webp`：香港中學圖書館／教室內的智能校園數據項目，包含條碼借閱、平板問卷、環境感應器、匿名統計圖表及私隱同意提示。
- `computer-network-lab.webp`：學生在安全受監督的電腦室辨認 PC 組件、接駁 Ethernet switch／wireless router，並觀察小型伺服器機櫃。
- `software-web-project.webp`：由問題分析、無文字流程圖、程式編寫、網頁介面預覽到正常／邊界／不合法測試的完整開發情境；第二次生成編輯移除了原圖的英文標籤。
- `relational-database-project.webp`：把重複活動報名記錄整理成學生、活動及報名關係，經實體卡、橋接關係、數據表及查詢圖表表達。
- `smart-greenhouse-iot.webp`：溫度與土壤濕度感應器、微控制器、圖表、風扇、水泵及警示燈構成的 input—process—output 情境；第二次生成編輯移除了原圖的英文標籤。

所有 prompt 共用要求：scientific-educational、寬幅 16:9、真實香港中學學習情境、準確可辨認的硬件與流程、自然光、indigo／teal 主色、沒有可讀文字／代碼、沒有 logo、trademark 或 watermark。圖片以 WebP 品質 82 匯出，原始生成 PNG 保留在 ImageGen 的預設輸出資料夾。
