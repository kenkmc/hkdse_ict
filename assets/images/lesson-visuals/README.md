# 原創課題教學圖片

本資料夾的圖片由 OpenAI 內建 ImageGen 於 2026-08-24 生成，供本項目課程頁的「圖像導讀」使用。圖片沒有內嵌文字、品牌標誌或第三方素材，中文標題、說明及替代文字均由網頁提供。

## 最終 prompt set

- `core-a-data-information.webp`：由條碼、鍵盤與感應器輸入，經分類計算形成圖表、數據表及決策資訊的 16:9 教學流程圖。
- `core-a-data-representation.webp`：二進制資料分支為像素／色彩、字符、聲音取樣與視像畫面／壓縮的 16:9 技術圖。
- `core-b-computer-system.webp`：真實比例電腦機箱與 CPU、暫存器、RAM、儲存裝置關係的等距技術圖。
- `core-c-internet-security.webp`：裝置、接達點、路由器、互聯網、伺服器、加密通道、防火牆及被阻擋威脅的網絡圖。
- `core-d-program-development.webp`：現實排隊問題經分析、流程圖、程式、追蹤測試、除錯成為可用程式的學習流程。
- `core-e-responsible-ict.webp`：AR、3D 打印、AI 人類監督、人體工學、私隱同意與知識產權的負責任科技使用情境。
- `elective-a-database-design.webp`：重複大表經鍵、關係、橋接表及正規化成關聯表，再產生查詢結果。
- `elective-b-web-application.webp`：瀏覽器表單、安全請求、伺服器驗證、數據庫讀寫與回應，以及常用網絡服務。
- `elective-c-algorithms-devices.webp`：排序、二分搜尋、stack、queue、linked nodes，以及 microcontroller、sensor、motor 和安全閾值。

所有 prompt 共用要求：scientific-educational、寬幅 16:9、清晰留白、indigo／teal 主色、準確可辨認的硬件或結構、沒有可讀文字／字母／數字、沒有 logo 或 watermark。
