4.3

公式 (Formula)

公式必須以 = 符號開始。電腦會依據運算符號的優先次序計算。

算術運算符號 (Operators)

  • + (加) =A1+B1
  • - (減) =A1-B1
  • * (乘) =A1*B1
  • / (除) =A1/B1
  • ^ (指數) =A1^2

運算優先次序 (Priority)

  1. 括號 ( )
  2. 指數 ^
  3. 乘 * 、 除 /
  4. 加 + 、 減 -

例子：

= 5 + 2 * 3

= 11 (不是 21)

4.4

函數 (Functions)

函數是預設的公式，用來簡化複雜的計算。以下是常用的函數及其應用。

基礎統計

  • =SUM(範圍)
    計算總和。例: =SUM(A1:A5)
  • =AVERAGE(範圍)
    計算平均值。例: =AVERAGE(B1:B5)
  • =MAX(範圍) / MIN(範圍)
    找出最大/最小值。
  • =COUNT(範圍)
    計算包含數字的儲存格數目。

條件邏輯

  • =IF(條件, 真值, 假值)
    判斷。例: =IF(A1>=50, "及格", "不及格")
  • =COUNTIF(範圍, 準則)
    計數符合條件。例: =COUNTIF(A1:A10, ">50")
  • =SUMIF(範圍, 準則, [加總範圍])
    加總符合條件。例: =SUMIF(B1:B10, "Apple", C1:C10)

文字處理

  • =LEN(文字)
    計算長度。例: =LEN("Hello") -> 5
  • =LEFT(文字, n)
    取左邊 n 字。例: =LEFT("A123", 1) -> "A"
  • =RIGHT(文字, n)
    取右邊 n 字。例: =RIGHT("A123", 3) -> "123"
  • =MID(文字, start, n)
    取中間字。例: =MID("HK1234", 3, 4) -> "1234"

查找參照 (Lookup)

=VLOOKUP(查閱值, 表格範圍, 欄號, [匹配模式])

垂直查找。在表格首欄找「查閱值」，傳回該列指定「欄號」的資料。

=XLOOKUP(查閱值, 查閱陣列, 傳回陣列, ...)

新一代查找函數。更靈活，不需要指定欄號。
