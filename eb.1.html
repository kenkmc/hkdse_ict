01 · Request–response

瀏覽器開啟網頁時發生甚麼？

互動流程

GET

常用於讀取資源；參數可出現在 URL。易於 bookmark，但不應把密碼等敏感資料放在 URL。

POST

常用於提交或改動資料；資料放在 request body。仍需 HTTPS、驗證及伺服器端檢查。

Clients & Servers共享服務

Read

查看或複製檔案內容，但不能改寫。

Write

建立、更改或刪除內容；應只授予有需要人士。

Execute

執行程式或腳本，不等於可查看或修改檔案。

04 · Original DSE-style practice

學校網絡更新：8 分

8 分
原創練習按公開課程範圍設計，並非歷屆試題。
學校為流動裝置自動設定網絡，集中管理學生登入，並限制部分網站。校內網站會讀取一個學生資料表。

  1. (a) 分別指出處理自動網絡設定、集中登入及網站限制的服務。

    [3 分]

    DHCP server（1）、domain controller（1）、proxy server（1）。

  2. (b) 描述由學生提交查詢至顯示結果的 request–response 過程。

    [3 分]

    Browser 向 web server 發出 HTTP request（1）；server-side script 驗證並查詢 database（1）；server 回傳 response，browser 顯示結果（1）。

  3. (c) 解釋為何學生共享資料夾通常不應獲 execute 權限。

    [2 分]

    學生只需讀寫學習檔案（1）；execute 可讓惡意／未授權程式運行，增加保安風險（1）。
