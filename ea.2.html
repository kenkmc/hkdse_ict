02 · Multi-table query

把「5A 學生姓名」拆成五個評分點

STUDENT S
  • SID · PK
  • SName
  • ClassID · FK
CLASS C
  • ClassID · PK
  • ClassName
SELECT S.SName
FROM STUDENT S
INNER JOIN CLASS C ON S.ClassID = C.ClassID
WHERE C.ClassName = '5A'
ORDER BY S.SName ASC;
JOIN 選擇：INNER JOIN 只保留配對記錄；LEFT OUTER JOIN 仍保留左表未配對記錄；NATURAL JOIN 依同名欄位自動配對，必須先確認欄名設計。

03 · Aggregates and subqueries

先算平均，還是先分班？

GROUP BY／HAVING

SELECT ClassID, AVG(Score)
FROM RESULT
GROUP BY ClassID
HAVING AVG(Score) > 70;

每班形成一個群組，再保留平均分高於 70 的群組。

一層子查詢

SELECT SID
FROM RESULT
WHERE Score > (
  SELECT AVG(Score) FROM RESULT
);

內層先回傳平均分，外層再逐筆比較。
