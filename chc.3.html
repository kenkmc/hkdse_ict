02 · Source evaluation

同一主題，三個來源的證據強度不同

按「分析可信性」查看可取分的判斷。可信性不是只看網址結尾，也不是把所有個人網站一律視為錯誤。

Source A

具名大學研究中心報告

三個月前更新，列出作者資格、研究方法、樣本和參考文獻。

較強：作者、日期、方法和證據均可核實；仍應檢查研究限制及與其他來源比較。

Source B

匿名「專家」社交帖文

沒有日期、資料來源或作者背景，只有「人人都知道」的說法。

較弱：權威、時效及證據均不能核實；分享次數不能代替可靠證據。

Source C

產品公司的比較文章

資料新而且有測試表，但只比較自家產品，頁面包含購買連結。

需審慎：資料可能有用，但有商業利益和選擇性比較風險；應核對方法並找獨立來源印證。

03 · Web multimedia formats

格式選擇要回應內容和網頁需要

照片

JPG 以有損壓縮減少相片大小，適合色彩連續的照片；反覆編輯儲存可累積失真。

圖示／透明背景

PNG 支援無損壓縮和透明度，適合界面圖示、標誌及需要清晰邊緣的圖像。

向量圖形

SVG 可按不同尺寸縮放而不失去幾何清晰度，適合簡單圖示和圖表；不適合直接保存一般照片。

聲音

常用有損音訊壓縮可大幅減少傳輸量，適合語音及音樂串流；品質受編碼設定影響。

視像

MP4 是常見容器，可配合適當編碼在瀏覽器傳送視像與聲音；實際支援視瀏覽器與編碼而定。

播放支援

現代瀏覽器多內置播放器；課程所述 plug-in／player 概念重點是用戶端需要能解碼和播放媒體。

04 · Internet services

按工作目的配對服務

✉

電郵

非同步傳送訊息和附件，可保留通訊紀錄。

⇅

檔案傳送

在本機與遠端主機之間上載或下載檔案。

>_

遠端登入

在另一地點操作遠端電腦或伺服器。

●

網上聊天

參與者通常同步交換短訊、聲音或視像。

☷

討論區

以主題串非同步發布、回覆和保存討論。

保安連結：傳送敏感檔案或遠端登入時，要使用加密版本的服務及適當身分認證；「可以傳送」不代表「傳送過程已安全」。

05 · Streaming simulator

緩衝如何應付網速波動

可操作

串流在完整媒體檔案下載前開始播放。按不同網速，觀察緩衝區為何只能應付短暫波動。

Buffer state

互聯網電話／視像會議

即時串流聲音和影像；延遲和抖動會直接影響對話流暢度。

Webcasting／隨選視像

向大量觀眾發布直播或預錄媒體；可按網絡狀況調整品質。

社會應用：IoT 裝置可收集並傳送感應數據，雲端服務可集中儲存、處理及提供應用，支援智能交通、環境監察和遙距服務；同時要考慮私隱、網絡依賴及保安。

06 · Original DSE-style practice

網上專題學習：8 分

8 分
原創練習按課程範圍和公開評核常見情境編寫，並非歷屆試題或官方擬題。
學生要製作「香港城市綠化」專題網站，搜尋資料、訪問外地專家並在網頁加入訪問錄影片段。

  1. (a) 建議兩種方法改善搜尋結果的相關性。

    [2 分]

    每項合理方法 1 分，例如使用具體詞組／引號、加入地點和研究面向、限制可靠網站或日期、排除不相關字詞。

  2. (b) 學生找到匿名而沒有日期的網誌。解釋兩項可信性問題。

    [2 分]
    • 作者身分／資格不能核實，權威成疑（1）。
    • 沒有日期，不能判斷內容是否仍然最新和適用（1）。

  3. (c) 建議一種適合與外地專家即時對話的服務，並解釋。

    [2 分]

    視像會議／網上聊天（1），可讓不同地點參與者即時、雙向傳送聲音和影像（1）。

  4. (d) 說明串流如何讓訪客在未下載完整影片前開始播放，以及緩衝的作用。

    [2 分]
    • 播放器接收部分媒體數據後便一邊下載一邊播放（1）。
    • 緩衝預先保存一部分數據，以應付短暫網速波動／減少停頓（1）。
