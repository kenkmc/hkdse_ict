02 · Operating system

操作系統的六項基本功能

不同操作系統的介面和應用場景可不同，但答案應集中它們如何分配資源、保護資料及支援程式運行。

Processor

處理器管理

排程程序，分配 CPU 時間，讓多個工作看似同時運行。

Memory

記憶體管理

分配和回收 RAM，避免不同程序不當存取彼此的記憶空間。

File

檔案管理

建立資料夾、命名、儲存、搜尋、複製及設定檔案存取權限。

Device

裝置管理

透過驅動程式控制打印機、顯示卡等周邊裝置並協調輸入輸出。

Interface

使用者介面

提供 GUI 或命令列，讓使用者輸入指令並查看系統回應。

Security

保安與存取控制

管理帳戶、身分驗證、權限和系統紀錄，限制未獲授權的存取。

03 · Utilities and drivers

維護系統，還是控制指定硬件？

Data compressor

數據壓縮程式

減少檔案所需儲存空間，亦可縮短在相同傳輸率下的傳送時間；是否有損須視方法而定。

Virus checker

病毒檢查程式

掃描檔案和活動，比對惡意程式特徵或可疑行為，並隔離、封鎖或移除威脅。

File manager

檔案管理程式

協助建立資料夾、搜尋、複製、移動、重新命名及刪除檔案。

Defragmenter

磁碟重組程式

重新排列磁碟上分散的檔案區塊，減少機械讀寫頭移動；一般不應用來重組 SSD。

System monitor

系統監察程式

顯示 CPU、記憶體、儲存及網絡資源用量，協助找出效能問題。

Device driver

驅動程式

讓操作系統與指定硬件溝通，把通用要求轉成裝置可理解的控制方式。

OS ↔ 指定硬件

05 · Original DSE-style practice

校園伺服器與防毒系統：9 分

9 分
原創練習按課程範圍及公開評核的情境式問法編寫，並非歷屆試題或官方擬題。
學校把網頁、測試及檔案服務放在同一部實體伺服器的三個獨立環境。防毒軟件會在檔案開啟前檢查，也會在每晚 2 時一次掃描當日新增的所有檔案。

  1. (a) 指出讓三個獨立環境共用一部實體伺服器的操作模式，並說明一項好處。

    [2 分]

    虛擬化（1）；多個隔離環境可共享同一部實體伺服器，提高硬件資源使用率／減少實體設備成本／方便獨立測試及復原（任何一項合理好處，1）。

  2. (b) 分別指出「檔案開啟前檢查」和「每晚一次掃描」的操作模式，並各以題目資料解釋。

    [4 分]
    • 檔案開啟前檢查：實時處理（1），因系統須在程式執行事件發生時立即回應並封鎖威脅（1）。
    • 每晚一次掃描：批次處理（1），因檔案先累積，再在預定時間集中處理（1）。

    只用「一個／多個檔案」比較不能完整解釋；評分重點是事件時限和累積／排程。

  3. (c) 說明打印機驅動程式的主要功能，並指出使用正確版本的一項需要。

    [2 分]
    • 讓操作系統與指定打印機溝通／控制它（1）。
    • 正確版本可支援該硬件型號或目前操作系統，避免不相容和錯誤（1）。

  4. (d) 指出一種可查看 CPU 和 RAM 使用量的實用程式。

    [1 分]

    系統監察程式（system monitoring software）（1）。
