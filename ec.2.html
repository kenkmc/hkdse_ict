Library

提供已封裝函數來讀取 sensor 或控制 motor，減少直接處理硬件細節。

User event

例如按鈕、觸碰或語音命令；event handler 在事件發生時執行。

Sensor event

數值跨越閾值或裝置姿勢改變時觸發，例如 accelerometer 偵測搖動。

02 · Temperature controller

一個閾值會令風扇反覆跳動

互動模擬

超過 30°C 開啟；低於 28°C 才關閉。兩個閾值形成 hysteresis，避免讀值在 30°C 附近時頻繁切換。

IF temperature > 30 THEN
    fanOn ← TRUE
ELSE IF temperature < 28 THEN
    fanOn ← FALSE
END IF

03 · Events and safe behaviour

不要假設感應器永遠正確

Range check

拒絕超出裝置物理範圍的讀值，並記錄故障。

Debounce

避免機械按鈕一次按下產生多個短促事件。

Timeout

長時間收不到讀值時進入安全狀態或通知使用者。

Manual override

讓獲授權人士在緊急時停止 motor 或改用手動控制。

裝置功能例子：speech recognition 把語音轉成指令；accelerometer 量度加速度和方向改變。答題須交代事件如何連到 handler 及輸出。

04 · Original DSE-style practice

智能溫室：8 分

8 分
原創練習按公開課程範圍設計，並非歷屆試題。
溫室程式使用溫度感應器和 motor 驅動通風窗。當溫度過高便開窗；工作員亦可按下緊急按鈕停止 motor。

  1. (a) 指出此系統的 sensor、actuator 和一個 user event。

    [3 分]

    溫度感應器（1）、motor／通風窗（1）、按下緊急按鈕（1）。

  2. (b) 描述由高溫事件至開窗的處理。

    [3 分]

    Library／程式讀取溫度（1）；handler 判斷高於閾值（1）；呼叫控制函數啟動 motor 開窗（1）。

  3. (c) 建議一項感應器故障的安全處理並說明原因。

    [2 分]

    合理安全處理（1），例如 timeout 後停止 motor／通知工作員；能連結避免設備受損或失控（1）。
