## 目標與依據

讓教師可用同一套課文、示例、工作紙、實作與評估資料備課，讓學生由必要術語與先備檢查，逐步做到獨立計算、追蹤、實作、解釋與陌生情境遷移。5** 是能力訓練方向，不是本站可以認證或保證的成績；不把練習百分比、自評、已讀或動畫數目換算成等級。

範圍依據[教育局 2021 課程及評估指引](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/technology-edu/curriculum-doc/ICT_C%26A%20Guide_c_final.pdf)及[課程文件索引](https://www.edb.gov.hk/tc/curriculum-development/kla/technology-edu/curriculum-doc/index.html)：五個必修單元、三個選修的教材，以及 SBA 的方法與證據流程；學生按學校修讀其中兩個選修。內容包括課程內核心技能，另以明示的延伸或教學模型訓練推論。年度考核與 SBA 題目、時限、可接受協助及正式評分依當屆校方安排，本次沒有以原創題替代或改寫官方考核文件。

## 學生與教師如何使用

- 課文：先備檢查、中英術語、連貫解說、逐步示例、數據／程式／表格與每節四選項診斷。每個選項有自己的解釋，答錯可回看運作原因。
- 練習：基礎、情境作答及高階遷移三層。先寫下嘗試才揭示完整範答與逐分點；沒有文字自動閱卷，自評需教師或同儕核對。
- 實作：工具、材料、操作、應交成果、測試輸入與預期結果均列出。SQL、程式與網頁提供可重現資料或程式，不只叫學生另找例子。
- 教學：各單元有課前診斷、可調整的課堂活動、時間及證據、支援／伸展、離堂題、課業與評估提醒。建議教案時間不是官方課時表，也不是每位學生完成整個課題所需時間的保證。
- 工作紙：學生列印包含課文、逐步示例及無範答的獨立題；教師列印另含教案、答案及逐分點。教師可另設未見題作正式評核，公開答案不當作保密試卷。
- 路徑：必修循序學習，選兩個選修；未選齊會提示。診斷、獨立作答、自評及實作證據分開記錄，不以單次答對或瀏覽計成掌握。
- 高階：必修整合及 A+B／A+C／B+C 組合任務，練習分析資料、處理邊界、比較取捨、驗證假設及有條件的結論；再連到現有作答實驗室、錯題重練及限時模擬考。

## 資料、保存與整合

`course-manual/data/` 的四份單元 JSON 與 `integrated.json` 是教材來源。`manual-core.js` 處理診斷、路徑與本機狀態；`manual.js` 用純文字轉義呈現課文及答案，`manual.css` 控制閱讀、手機與兩種列印。

既有永久課題 ID 不變，主站及分課導覽連到相應手冊，原有動畫、題庫、SQL／PKI／Python 工具繼續使用。手冊沒有新項目宣傳標示。

答案、證據索引及兩個選修保存在 `hkdse-ict-manual-v1`，納入「我的學習」JSON 備份。修改答案會清空舊自評點；題幹／選項／答案改變後，舊診斷不會當作新題的成功證據。其他分頁清除或還原資料後，手冊會重新載入狀態，避免把已清除筆記寫回。

備份匯出及匯入使用同一 32 MiB 上限；匯入先準備所有新值，任一儲存失敗則回復原值，不顯示半匯入成功。瀏覽器拒絕儲存或回復也失敗時，會明確提示保留原檔及本機資料。學習筆記與實作檔案不自動上載；校園同步仍只用原有最少化摘要。

## 實作界線

文字與模擬不能代替真正執行。試算表要保存含公式的原檔；網站前端可在靜態主機執行，Python／SQLite 教學服務需另開本機環境；隔離 LAN、跨機、感應器、馬達及實物製造需合適設備及教師安排。程式中的教學會話／帳戶不是正式部署的完整保安方案。

SBA 手冊用 M1／M2／M3 標示練習需求；既有模型各有自己的 R 代號與功能。姓名版本檢查、時間衝突及證據追蹤是分離模型，不冒稱整合的可儲存／取消預約系統。正式作品需學生自己的分析、實施、來源、版本、測試及評估。

社會影響內容另包括性別公平、本地與全球差距，以及香港侵權的法律後果和教育使用條件。法律教學核對知識產權署資料，沒有對個別事件作法律裁決，也不把教育用途一概視為豁免。

## 驗證

可重跑：

```text
node scripts/validate_manual.js
node tests/manual-backup.cjs
node tests/manual-ui.cjs
python tests/manual-data.py
python tests/manual-programming.py
python tests/manual-network.py
node tests/manual-network.cjs
```

`manual-ui.cjs` 使用 jsdom 26.1.0 作純 DOM fixture。可在測試目錄安裝該套件，或用 `MANUAL_JSDOM_MODULE` 指向既有安裝；不把依賴部署到 GitHub Pages。它沒有開啟真瀏覽器，也沒有使用真實校園帳戶或資料。

自動驗證包括全單元與前置關係、每節課文／示例／四選項回饋、三級題與逐分點、教案時間、資料連結、題目版本、修訂後自評、兩選修路徑、答案轉義、本機保存、學生／教師列印來源分離、跨分頁清除及備份還原／quota 失敗回復。

本輪真瀏覽器工具啟動時因找不到所需工具檔案而失敗，重設後仍相同，2026-10-19 重試亦未能啟動；因此不宣稱已完成新介面的真瀏覽器版面、鍵盤或列印視覺測試。先前 2026-10-17 的 85 頁桌面／手機紀錄只屬當時版本。程式、SQL、HTTP handler 與純 DOM 的成功也不等於學生試學成效、實物或跨機測試。
