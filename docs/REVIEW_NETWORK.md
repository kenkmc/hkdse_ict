# 互聯網、保安及選修 B：逐頁、逐節檢視

日期：2026-10-16。範圍為 8 個主站頁面及 12 個獨立教材頁面，共 20 頁。本文件記錄實際閱讀的文字、原有互動、圖片及練習，不把「每頁有一個動畫」當作逐節完成。

## 實施原則與去重結果

- 每個模型只在同一頁的一個相關段落出現。掛載位置寫入 `assets/js/lesson-plan-network.js`，不在頁首另設模型展示區。
- 兩份 `chc.2` 的原 TCP 畫布、DNS 文字計時器及對應程式已移除，以 TCP 序號／ACK／重傳及獨立 DNS 快取／TTL 模型取代。IP 設定指令、HTTP／HTTPS 及電郵移動動畫保留，各自解釋不同機制。
- 主站 `chc.3` 固定三個網速狀況的緩衝示意被可調輸入／輸出速率的緩衝槽取代；搜尋組合器及來源評估保留，沒有再加入相同操作。
- 主站 `chc.4` 的 HTML 點選高亮示例被可編輯的 HTML／DOM／渲染模型取代。文件骨架、連結、圖片與 alt 說明保留；受眾設計即時預覽保留，不再疊加另一個相同設計預覽。
- `eb.1`／`eb.2` 的通用五步點選流程移除，改由請求封包、HTTP 原文、實際表單驗證及資料庫紀錄說明。
- 獨立 `chc.1` 的兩個舊架構畫布移除，架構角色及管理特點文字保留，改用一個可切換 P2P／中央伺服器、加入請求及模擬故障的機制。
- 兩份原 PKI 工具使用明確空計畫 `[]`，不再加上另一個加密／簽署模型。保留原本 Alice／Eve／Bob 操作，加入「竄改明文但保留原簽章」分支，Bob 驗證時會失敗。
- DHCP 不再包含附加的權限操作；權限獨立放在共享權限段落。表單模型不再兼做 cookie 模型；cookie 另放在狀態段落，避免跨段重複。
